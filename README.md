# Hospital Performance Analytics Dashboard

## Project Overview

A completed hospital performance analytics project developed using Microsoft Power BI, Power Query, DAX and Excel. The project demonstrates how hospital data can be transformed into structured information to support financial, operational and clinical performance analysis.

## Project Objectives

- Analyse hospital revenue and financial performance.
- Examine patient activity and service utilisation.
- Assess departmental performance.
- Identify patterns in diagnoses and treatment types.
- Develop interactive dashboards to support evidence-based management decisions.

## Key Performance Indicators

- Total Revenue
- Total Patients
- Average Revenue per Patient
- Diagnosis Type
- Treatment Type
- Readmission

## Key Analytical Questions

1. Which departments generate the highest revenue?
2. How has revenue changed over time?
3. Which diagnoses account for the highest number of patient visits?
4. Which treatment types are most frequently provided?
5. How are patient visits distributed across insurance providers?

## Tools and Technologies

| Tool | Application |
|---|---|
| Microsoft Power BI | Interactive dashboard development and visualisation |

| DAX | Measures and performance calculations |
| Microsoft Excel | Data source and preparation |

## Data Preparation and Modelling

The project involved data profiling, cleaning and transformation in Power Query, followed by the development of a structured data model. Dimension tables and a fact table were used to organise the analytical data. DAX measures supported the calculation of key performance indicators.
